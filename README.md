모바일 OTP 인증기 (Mobile OTP Authenticator)
1. 프로젝트 소개

이번 프로젝트에서는 Google Authenticator와 같은 방식으로 작동하는 나만의 모바일 OTP 인증기 웹앱을 제작했다.

인터넷 연결 없이도 브라우저 내부에서 30초마다 새로운 6자리 인증번호를 생성하고 검증할 수 있도록 구현했다.

2. AI 협업 및 개발 방식

Gemini를 활용하여 앱의 화면 구성과 기능을 기획하고, Antigravity IDE를 사용하여 React 기반 웹앱을 구현했다.

AI가 제안한 Implementation Plan을 검토한 뒤 기존 코드를 유지하면서 기능을 개선하는 방식으로 진행했다.

개발 과정에서의 시행착오
QR 코드를 스마트폰 Google Authenticator와 연동하는 과정에서 URI 형식과 계정명 구분을 점검했다.
PC와 스마트폰의 인증번호가 일치하는지 확인하기 위해 시간 동기화와 30초 갱신 로직을 점검했다.
Base32 인코딩 및 디코딩 과정에서 발생할 수 있는 오류를 확인했다.
브라우저 개발자 도구의 Network 탭을 이용해 외부 데이터 전송 여부를 확인하는 방법을 익혔다.
3. 사이버보안 적용
암호학적 난수 생성

crypto.getRandomValues()를 사용하여 예측하기 어려운 비밀 키를 생성했다.

일반 난수 함수인 Math.random()은 사용하지 않았다.

Web Crypto API 활용

crypto.subtle을 이용하여 HMAC-SHA1 연산을 브라우저 내부에서 수행하도록 구현했다.

RFC 6238 규격에 따라 30초 단위의 시간 카운터를 사용하여 6자리 OTP를 생성했다.

Zero-Transmission 검증

브라우저 개발자 도구의 Network 탭에서 네트워크 요청을 확인했다.

비밀 키와 OTP 인증번호가 외부 서버로 전송되지 않는지 확인하는 과정을 진행했다.

4. 프로젝트를 통해 배운 점

이번 프로젝트를 통해 단순히 화면을 구현하는 것뿐만 아니라 인증 시스템의 작동 원리와 사이버보안의 중요성을 배웠다.

특히 TOTP 알고리즘, Base32, HMAC-SHA1, Web Crypto API의 관계를 이해하고 스마트폰 인증 앱과 연동하면서 시간 동기화의 중요성을 직접 경험했다.

또한 AI를 단순한 코드 생성 도구가 아니라 기획, 구현, 디버깅 및 검증을 함께 진행하는 개발 협업 도구로 활용할 수 있다는 점을 배웠다.
